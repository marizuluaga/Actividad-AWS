## Descripción

Repositorio desarrollado para la actividad práctica de servicios de AWS en la región `us-east-2`.

## Puntos desarrollados

1. AWS Secrets Manager e IAM.
2. Infraestructura con Terraform, Boto3 y AWS CLI.
3. Amazon DocumentDB, Secrets Manager y túnel SSH.
4. Amazon Neptune y consultas Gremlin.
5. Amazon Redshift Serverless, S3 y consultas SQL.
6. AWS Glue, Crawlers y Amazon Athena.

## Seguridad

Las contraseñas se administran mediante AWS Secrets Manager. Los archivos de estado, entornos virtuales, certificados y credenciales locales están excluidos mediante `.gitignore`.
